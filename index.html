Enable Firestore Rules (budget-system-67273)

Your data is safely saved locally. Update Firestore Rules to sync across devices.

In Firebase Console → Firestore Database → Rules, paste and publish these rules so your account documents can sync: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /von_allocator_users/{userId}/{document=**} {
      allow read, write: if true;
    }
    match /von_allocator_accounts/{userId} {
      allow read, write: if true;
    }
  }
}
