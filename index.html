Instant Native App (Zero Build Required)

Android Chrome automatically packages PWAs as a native WebAPK in your app drawer, and Windows/Mac browsers install it as a standalone Desktop Window with no address bar.

Android Phone (Chrome / Edge / Brave)

Tap the browser menu (⋮) → Add to Home screen → Install. Android installs a real native WebAPK icon on your phone.

Windows / Mac Desktop (Chrome / Edge)

Click the Install icon on the right side of the URL bar (or menu → Save and share → Install page as app) to pin it to your Taskbar / Dock.

iPhone / iPad (Safari)

Tap the Share button → Add to Home Screen to launch full-screen like a native iOS app.

Compile Standalone Android .APK (Capacitor) Android 8–15

Save this HTML file inside a folder named www/index.html, download the config files below, and run these 4 commands to generate your installable app-debug.apk:

npm install npx cap add android npx cap sync android cd android && ./gradlew assembleDebug
No Android Studio? Free Cloud APK Option:

Host index.html on GitHub Pages / Vercel / Netlify, paste the URL into PWABuilder.com, and download a signed Android .apk in 30 seconds.

Build Desktop App (.EXE / .DMG / .AppImage) Electron

Put index.html alongside the downloaded electron-main.js and package.json, then run:

npm install npm start # Build Windows .exe or macOS .dmg installer: npm run dist
Your Firebase Cloud account (von) syncs automatically between your Android APK and Desktop executable in real time.
